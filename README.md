# Sistema de Rescate y Adopción Animal

Sistema de control de rescate y adopción animal.

## Descripción del proyecto

Proyecto académico orientado al desarrollo de un sistema para gestionar los casos de rescate y adopción animal, facilitando el registro de animales, el seguimiento de los casos y la administración de los procesos de adopción.

## Estructura del proyecto

- `index.html`: página principal del sistema.
- `reportar.html`: formulario para registrar reportes de animales que necesitan rescate.
- `rescates.html`: página con el listado de casos de rescate.
- `README.md`: documentación general del proyecto.

## Funcionalidades previstas

- Registro de casos de rescate.
- Creación de expedientes de animales.
- Notificación a voluntarios.
- Gestión de animales para adopción.

## Arquitectura

El sistema utilizará el patrón arquitectónico MVC y los patrones de diseño Singleton, Observer y Factory Method.

## Corrección urgente (Hotfix)

Se contempla una corrección urgente para mantener el funcionamiento adecuado del sistema de rescate y adopción animal.

- Validación de los datos ingresados en los casos de rescate.
- Prevención de registros incompletos.
- Verificación de la información antes de crear un expediente animal.

En esta actividad se desarrolla el prototipo inicial de la interfaz web del sistema, utilizando HTML5 y etiquetas semánticas para organizar el contenido y facilitar la navegación entre sus páginas.
